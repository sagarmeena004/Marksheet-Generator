# 🎓 Student Marksheet Generator Using Python

A simple and interactive **Student Marksheet Generator** developed using Python.

This console-based application generates a university-style marksheet by collecting student information, theory marks, and practical marks.

The project demonstrates fundamental Python programming concepts such as user input, variables, conditional statements, arithmetic operations, and formatted output.

## 🚀 Features

- Student information management
- Enrollment and roll number entry
- Semester and section details
- Subject-wise marks entry
- Theory and practical marks calculation
- Automatic PASS/FAIL evaluation
- University-style marksheet display
- Simple command-line interface

| Technology | Purpose |
|---|---|
| Python | Core Programming Language |
| Python Built-in Functions | Input and Output |

| Arithmetic Operators | Marks Calculation |

## 💻 How It Works

1. Run the Python script.
2. Enter student details.
3. Enter marks for all five subjects.
4. Enter practical marks for Physics, Chemistry, and Biology.
5. The program calculates combined marks for practical subjects.
6. The application displays a formatted marksheet with individual PASS/FAIL results.

## 📊 Passing Criteria

The current program uses the following conditions:

| Subject | PASS Condition |
|---|---|
| Hindi | Marks > 28 |
| English | Marks > 28 |
| Physics | Theory + Practical > 33 |
| Chemistry | Theory + Practical > 33 |
| Biology | Theory + Practical > 33 |

These conditions reflect the existing Python implementation.
