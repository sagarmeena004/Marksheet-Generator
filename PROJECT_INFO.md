## 📖 Project Description

Student Marksheet Generator is a Python application that generates academic marksheets using student information and examination marks.

The application collects student details, processes theory and practical marks, and displays subject-wise PASS/FAIL results.

## 🎯 Project Purpose

The primary purpose of this project is to demonstrate basic Python programming concepts through a practical academic application.

It focuses on:

- User input handling
- Student information processing
- Marks calculation
- Conditional statements
- Formatted output

## 📚 Academic Subjects

The project supports five subjects:

1. Hindi
2. English
3. Physics
4. Chemistry
5. Biology

Physics, Chemistry, and Biology include practical marks.
