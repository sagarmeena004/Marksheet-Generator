# Changelog

All notable changes and documentation updates for the Python Marksheet Generator project are recorded in this file.

## [1.0.0] - 2026-10-24

### Added

- Initial Python Marksheet Generator application.
- Student information input functionality.
- Enrollment number and roll number input.
- Semester and section information.
- Scholar number input.
- Hindi and English theory marks entry.
- Physics, Chemistry, and Biology theory marks entry.
- Practical marks input for science subjects.
- Automatic calculation of combined marks for practical subjects.
- Subject-wise PASS/FAIL evaluation.
- Formatted university-style marksheet output.

### Documentation
